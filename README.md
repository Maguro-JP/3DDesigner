# 3DDesigner

2D形状データを3Dメッシュに変換する独立ツールです。今できるのは単一輪郭から閉じた三角形メッシュを生成し、OBJ/GLBに書き出すことです。ブラウザー画面からFashionDesignerの形状JSONを直接読み込めます。

## 起動方法

Python 3.10以降があれば、追加パッケージ不要です。

```bash
python server.py
```

`http://127.0.0.1:8766/` を開き、FashionDesignerが出力したJSONを選択し、厚みを入力してOBJまたはGLBを書き出します。

4方向画像を使う場合は、画面の「4方向画像から視覚殻を作成」を開き、正面・背面・左右側面を読み込みます。4方向のシルエット交差からGLBを生成し、生成メッシュの投影と入力シルエットのIoUを各面別に表示します。合成された整合形状で100%になることはテスト済みです。

## API

`POST /api/mesh?format=glb` または `format=obj`

```json
{"points":[[0,0],[100,0],[100,200],[0,200]],"depth":20,"unit":"mm"}
```

レスポンスはOBJ/GLBのファイルです。不正輪郭、面積ゼロ、自己交差、0以下の厚みは拒否します。サーバーはlocalhostのみで待ち受けます。

4面のJSONマスクを `POST /api/visual-hull` に送るとGLBを返し、`X-Silhouette-Scores` に4方向のIoUを返します。初期解像度は幅32×高さ64×奥行32です。マスクを投影し直した結果が元マスクと一致しない場合、100%未満の値をそのまま返します。

## 現在の限界

4方向の処理はシルエット制約から得る視覚殻であり、隠れた形状の真の復元ではありません。単一画像から未撮影の3面を正確に知ることはできません。4方向が同じ正投影・位置・縮尺でない場合は一致率が下がります。材質・色・内部構造・衣服パネル縫合・布しわ・人体への着装は未実装です。現在の成果を衣服シミュレーションや任意画像の完成3D化とは扱いません。

次は共通形状形式にパネル・境界・縫い合わせ関係を定義し、CharacterDesignerの人物形状とFashionDesignerの衣服形状を共通座標で扱い、着装と干渉を検証します。

## 検証

```bash
python -m unittest -v test_mesh_core.py
python -m unittest -v test_visual_hull.py
```

凹形状の三角化と面積、閉メッシュ、外向き体積、OBJ面、GLB header/chunk、無効輪郭を検証します。Blender等での見た目と人物への着装は別途確認が必要です。

4面テストでは整合した4投影のIoUが各100%になること、矛盾入力では100%未満になること、GLB header/chunkが有効なことを確認します。
